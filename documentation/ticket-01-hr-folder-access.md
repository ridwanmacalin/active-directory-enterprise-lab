# Ticket 01 - HR Folder Access

## Issue

A user was able to access the HR folder even though they were not supposed to have permission.

## Investigation

I reviewed:

- Active Directory group membership
- Share permissions
- NTFS permissions

## Resolution

The permissions were corrected so that only authorized HR users could access the folder.

## Skills Used

- Active Directory
- Security groups
- NTFS permissions
- File sharing
- Troubleshooting
