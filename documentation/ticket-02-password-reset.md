# Ticket 02 - Password Reset

## Issue

A user forgot their password and could not log in.

## Troubleshooting

I opened Active Directory Users and Computers and located the user's account.

I verified that the account was active and then reset the user's password.

## Resolution

The password was reset successfully.

The user was able to log in with the new temporary password.

- Active Directory
- User account management
- Password reset
- Help desk troubleshooting
