# Ticket 03 - Account Unlock

## Issue

A user was unable to log in because their Active Directory account was locked.

## Troubleshooting

I located the user's account in Active Directory Users and Computers.

I checked the account status and confirmed that it was locked.

## Resolution

I unlocked the account and verified that the user could log in again.
