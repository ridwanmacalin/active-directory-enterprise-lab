Ticket 01 - Password Reset

Issue

A user was unable to log in because they needed their password reset.

Environment

Windows Server

Active Directory Domain Services

Domain: adlab.local

Troubleshooting

I opened Active Directory Users and Computers and located the user's account.

I reviewed the account to make sure it was enabled and available for authentication.

Resolution

I used Active Directory Users and Computers to reset the user's password.

After completing the reset, I verified that the account was still enabled and ready for use.

Verification

Confirmed that the password reset was completed successfully.
